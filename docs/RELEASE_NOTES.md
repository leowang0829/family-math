# v0.2.0 · 统一公开版

产品统一为「爱数学 · Family Math」，一个 App、一个启动命令、一个默认数据目录与一个容器服务。

移除双产品命名、人物身份与固定地区、年级、出版社和页码绑定。知识地图改为原创数学知识卡、例题与练习，保留拍题、错题重做、分步讲解、手写草稿、每日五题、打印、打卡与家庭奖励。

公开包仅包含程序、原创内容与合成测试样本，不包含真实照片、学习数据库、密钥或家庭密码。模型分工保持 Max＋Flash。旧实例未被更新，学习记录未改动。

发布验证涵盖 Python 接口与后台流程、前端逻辑检查和全新临时数据目录的启动、家庭连接、学习及打印入口。此次检查不调用付费模型。Docker、真实 iPad 与实体打印未在发布环境重测。
