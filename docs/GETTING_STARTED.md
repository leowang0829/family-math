# 开始使用爱数学

## 1. 启动与连接

按项目首页运行 `python run.py`，打开 `http://127.0.0.1:8921/`。在后台所在电脑打开 `/setup`，填写自己的百炼密钥，检测连接，并查看家庭连接码。默认模型分工使用 Max 与 Flash，密钥需要允许对应模型调用。

用学习页面输入连接码后，照片与练习记录会保存在后台。局域网使用可用 `python run.py --bind 192.168.1.100`，将示例地址替换为后台设备的真实局域网 IP，并让 iPad 连接同一网络。

## 2. 拍题与错题

从“拍一拍”使用相机或相册。上传后自动识别、批改并逐题返回结果；老师标错、AI 判错、未作答或不会做的题按流程收纳。识别不完整时保留原图并显示状态，避免把不确定的结果当成正确答案。

打开错题先重做原题，再看分步讲解。支持多小问、分数输入和手写草稿。原题整题做对一次显示已掌握，衍生题在温习中继续巩固。错题可批量选择练习、打印，也可从回收站恢复。

## 3. 学习与每日温习

学习地图按数学知识点组织，家长可在设置中选择当前主题和小节。知识卡、例题及规则练习可在无模型密钥时使用。

每日温习固定五题，优先选择未做过的变式。做错的练习会进入错题流程，重做与知识温习各自记录，避免进度混淆。

## 4. 打卡、钻石与打印

完成每日五题或成功订正一道错题，系统根据学习记录自动打卡。家长可以调整钻石奖励、兑换价格并确认兑换申请。

打印：勾选题目 → 准备题面并预览 A4 分页 → 打印。准备时间随题数与复杂度增加，打印前检查题干和图形。

## 5. 添加到 iPad 主屏幕

Safari 打开后台地址，连接学习空间后选择“分享 → 添加到主屏幕”。后台需要持续运行；电脑关机则本地后台停止。长期在线可部署到常驻家庭设备或云服务器，相机与 PWA 能力受 HTTPS 和系统版本影响。
